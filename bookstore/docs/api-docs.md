# Data REST API - URL-lista

## API pääsivu

`GET /api`

## Books

### Hae kaikki kirjat
`GET /api/books`

### Hakee yhden kirjan
`GET /api/books/{id}`

### Lisää uuden kirjan
`POST /api/books`

### Muokkaa kirjaa
`PUT /api/books/{id}`

### Poistaa kirjan
`DELETE /api/books/{id}`

## Categories
### Hae kaikki kategoriat
`GET /api/categories`

### Hakee yhden kategorian
`GET /api/categories/{id}`

### Lisää uuden kategorian
`POST /api/categories`

### Muokkaa kategoriaa
`PUT /api/categories/{id}`

### Poistaa kategorian
`DELETE /api/categories/{id}`

## Profile
### Data REST API profiilitiedot
`GET /api/profile`

### Books-rajapinnan profiilitiedot
`GET /api/books`

### Categories-rajapinnan profiilitiedot
`GET /api/categories`
